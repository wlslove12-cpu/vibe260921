## 1. 개요

### 1.1 배경
개발자 장미영의 역량과 작업물을 한곳에서 보여 주는 개인 프로필 웹사이트를 만든다. 주 개발 분야인 **바이브코딩, Python, HTML5**로 만든 실제 결과물을 방문자가 바로 실행해 볼 수 있게 하는 것이 핵심이다.

### 1.2 목적
- 채용 담당자, 협업 제안자, 의뢰인에게 개발자를 소개한다.
- 글로 설명하는 대신 **직접 실행해 볼 수 있는 데모**로 실력을 보여 준다.
- 방문자가 쉽게 연락할 수 있는 창구를 제공한다.

### 1.3 목표와 성공 기준
| 목표 | 성공 기준 |
|---|---|
| 첫인상으로 전문 분야 전달 | 첫 화면(스크롤 전)에서 이름, 역할, 주요 분야가 모두 보인다 |
| 작업물 체험 | 프로젝트마다 "실행해 보기" 링크가 있고 클릭 한 번으로 열린다 |
| 연락 유도 | 어느 화면에서든 연락처 섹션까지 한 번의 클릭으로 이동한다 |
| 빠른 로딩 | 모바일 4G 환경에서 첫 화면 표시 3초 이내 |
| 모든 기기에서 사용 가능 | 360px ~ 1920px 폭에서 레이아웃이 깨지지 않는다 |

### 1.4 범위 밖 (이번 버전에서 하지 않는 것)
- 로그인, 회원가입, 관리자 페이지
- 서버/데이터베이스가 필요한 기능 (블로그 댓글, 방문자 통계 저장 등)
- 다국어 지원 (1차는 한국어만)

## 5. 비기능 요구사항

| 구분 | 요구사항 |
|---|---|
| 반응형 | 모바일 우선 설계. 기준 폭 360 / 768 / 1024 / 1440px |
| 성능 | 첫 화면 3초 이내(4G), 이미지는 필요한 크기로 압축, 외부 라이브러리 최소화 |
| 접근성 | 시맨틱 태그 사용, 이미지 `alt`, 키보드만으로 모든 메뉴 사용 가능, 텍스트 대비 WCAG AA 이상, `prefers-reduced-motion` 존중 |
| SEO | `<title>`, `meta description`, Open Graph 태그, 제목 계층(h1은 페이지당 1개) |
| 호환성 | 최신 Chrome, Edge, Safari, Firefox와 모바일 브라우저 |
| 유지보수 | 프레임워크 없이 순수 HTML/CSS/JS. 파일 역할을 분리하고 색상·간격은 CSS 변수로 관리 |

## 6. 기술 스택

| 영역 | 선택 | 이유 |
|---|---|---|
| 마크업 | HTML5 (시맨틱 태그) | 주 개발 분야이며 정적 사이트에 충분 |
| 스타일 | CSS3 (Flexbox, Grid, 변수, 미디어 쿼리) | 프레임워크 없이 반응형 구현 |
| 동작 | 바닐라 JavaScript (ES6+) | 메뉴, 테마 전환, 프로젝트 렌더링 정도라 프레임워크 불필요 |
| 호스팅 | 정적 호스팅 (GitHub Pages 등) | 서버·비용 부담 없음 |
| 개발 방식 | 바이브코딩 (AI와 함께 구현하고 사람이 검수) | 개발자의 주 분야를 사이트 제작 과정에서도 보여 줌 |

> Python 작업물은 브라우저에서 실행되지 않으므로 소스 코드와 설명, 스크린샷(또는 짧은 영상)으로 소개한다.

## 7. 디자인 방향

- **인상:** 깔끔하고 신뢰감 있는 개발자 포트폴리오. 과한 장식은 피하고 작업물이 돋보이게 한다.
- **색상:** 포인트 색 1개 + 중립색(배경/글자). 다크 테마를 기본으로 하되 라이트 테마도 제공한다.
- **글꼴:** 본문은 시스템 한글 글꼴 스택(`Malgun Gothic`, `Apple SD Gothic Neo`, `system-ui`), 제목은 굵기로 위계를 준다.
- **레이아웃:** 콘텐츠 최대 폭 약 1100px, 카드 그리드(데스크톱 3열 / 태블릿 2열 / 모바일 1열).
- **상호작용:** 버튼과 카드에 호버·포커스 상태를 명확히 준다.
